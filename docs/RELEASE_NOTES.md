# PDFreader 2.2.2

适用于 Windows 10/11 x64 的预发行版。

- AI 对话新增第三方 OpenAI 兼容 API。可保存和切换多套配置，分别设置 API 地址、密钥、模型和流式输出。
- 提供 DeepSeek、通义千问、Kimi、智谱 GLM、小米 MiMo、Gemini 和 OpenRouter 模板，也可使用自定义兼容地址。服务支持时可读取模型列表。
- 设置入口改为「翻译配置」与「AI设置」。两处服务和密钥独立保存。
- 带更新功能的 2.2.2 安装包在「设置 → 应用更新」检查 GitHub Releases，下载更新并校验 SHA-256。确认安装前，应用会提示处理尚未保存的文档。

下载 [Windows x64 安装包](https://github.com/MPomelo/PDFreader/releases/tag/v2.2.2)，可用同页的 `SHA256SUMS.txt` 核对。安装包未签名。

已安装早期 2.2.2 的用户可以手动运行同一发布页的 `PDFreader_2.2.2_x64-updater-setup.exe`，用 `SHA256SUMS-updater.txt` 核对。之后可从应用内检查更新。

第三方 API 的配置切换和问答使用测试数据验证，尚未使用真实账户密钥逐项验证。

## PDFreader 2.2.1

适用于 Windows 10/11 x64 的预发行版。

- AI 对话支持「使用 ChatGPT 登录」。通过 OpenAI 官方页面授权后，可从账号实际可用的模型中选择。合资格的请求计入 ChatGPT 订阅用量，无需 API 密钥。
- 新增 Ollama 本地模型支持。输入 `@` 添加 PDF 当前页或选区、Markdown 和 TXT 资料，输入 `/` 使用可编辑的快捷命令。回复中的编号引用可定位原文。
- 下栏和右栏采用紧凑标签，修复加号菜单被分隔条遮挡的问题。重排上栏标签和工具栏，深浅主题使用相同的控件尺寸。
- 译文只占一个栏位，可按提示移栏。译文来源改用轻量随栏控件，译文区域取消独立工具栏。
- 「阅读与外观」中可分别调整界面字号与译文字号。

升级保留现有阅读设置、批注副本、译文缓存、笔记和对话历史。下载 [Windows 安装包](https://github.com/MPomelo/PDFreader/releases/tag/v2.2.1)，可用同页的 `SHA256SUMS.txt` 核对。安装包未签名。

ChatGPT 登录、模型选择和对话使用测试数据验证。真实账号的授权和订阅用量尚未实测。

## PDFreader 2.2.0

- 上栏、下栏和右栏可以同时显示 PDF、Markdown、TXT、译文和 AI 对话。用标签菜单或拖动移栏。各栏独立记住活动标签，移动保留正在编辑的文档和批注。
- 可调整、收起和临时最大化各栏。按 `F6` 和 `Shift+F6` 切换操作栏。应用恢复上次布局及可重新打开的本地文件。
- 译文标签可跟随指定栏位或固定到指定 PDF。后台翻译使用发起时选定的原文。
- AI 对话通过 OpenAI Responses API 和 Anthropic Messages API 提供流式、多轮对话。可加入 PDF 选区、当前页文字和文本选区，发送前审阅，按回复中的材料编号定位来源。支持停止、重试、临时会话、本地历史和 Markdown 导出。
- Windows 10/11 x64。对话需使用对应服务的 API 密钥，费用和隐私条款由服务商管理。OpenCode 的 Windows 进程隔离尚未验证，连接入口停用。

升级保留现有阅读设置、批注副本、译文缓存和笔记。布局只记录可重新打开的本地文件，不保存文档的未保存修改。安装包、SHA-256 校验文件和构建清单位于 [GitHub Release](https://github.com/MPomelo/PDFreader/releases/tag/v2.2.0)。

## PDFreader 2.1.2

- 在「批注 → 管理批注」中按页查看本次修改或全部批注，定位、删除，以及撤销或重做。跨页文字标记可整组撤销或删除。
- 下划线和删除线使用更细的笔画，在同一行连接普通词间空隙，保留分栏与分行的间隔。
- 选区注释统一在随主题变化的左侧栏中编辑。打开带批注的副本后，可以继续编辑 PDFreader 创建的注释。
- 「添加文本框」支持点击或拖动放置、多行中文、自动换行、字号和颜色，以及调整宽度、移动、编辑和删除。导出保留标准 PDF 文本批注和可编辑的文本内容。

### 文本框维护更新

- 文本框设置移到顶部工具栏下方，在添加、选中或编辑时显示。
- 文本输入区在编辑时使用实底。批注可选择透明或白底，白底随 PDF 副本导出。
- 拖动文本框顶部移动，拖动右侧手柄调整宽度。点击「完成」或按 `Ctrl+Enter` 返回阅读。

## PDFreader 2.1.1

- 新增 PDF 内部链接悬停预览，快速查看图表、参考文献条目或目标页。点击继续按原链接跳转。
- 图表或文献边界不明确时，显示目标附近的区域或整页缩略图。预览会在滚动、拖选或切换标签时收起。
- 缩小顶部加号弹出的文档菜单，收紧行高并将文字调整为 12 px。

## PDFreader 2.1.0

- PDF、Markdown 和 TXT 可在同一窗口打开或拖入。文本标签支持保存、另存为和关闭时的未保存提示。发现磁盘内容已更改时，可另存为保留编辑。
- Markdown 使用 CodeMirror 6，提供编辑、预览和左右分栏。预览支持离线 KaTeX、表格、任务清单、可复制的代码块和按语言高亮。
- 可插入、拖入或粘贴 Markdown 图片。已保存笔记的图片放在同名 `.assets` 目录，另存时复制所引用的托管图片并更新链接。网络图片需点击加载。
- TXT 提供撤销重做、查找替换和自动换行，状态栏显示行列号、编码和换行符。新文档使用 UTF-8，旧文档可选择编码。

## PDFreader 0.1.0-rc.1

首次公开的 Windows x64 候选版本。包含多 PDF 标签、独立批注、选区翻译、统一设置、本地缓存与笔记、可调侧栏及浅深主题。

新增单实例文件转发和按当前用户安装的 NSIS 包，支持中文与空格路径。安装注册可选“打开方式”，不替换系统默认 PDF 应用。修复宿主工具栏模式下查找面板继承隐藏样式的问题。

### 交付验证

- 65 项本地回归通过，覆盖阅读、翻译协议/取消、缓存、笔记、文件保护和标签状态；原生 HTTP 使用环回测试，凭据使用 dummy-key。
- 真实安装至含中文/空格的目录；经 Windows ShellExecute 的已注册打开方式打开文件，后续启动转发至同一窗口，原有标签缩放保留。
- 安装后使用嵌入资源离线阅读、搜索原文，通过实际 PDF.js 编辑器创建文本批注，经真实 Windows 保存对话框导出，pypdf 独立确认批注存在。
- 卸载移除测试 EXE 与打开方式注册；安装、卸载均未更改原来的 .pdf 默认值和 UserChoice。
- 浏览器六组多标签/UI 检查及 150% 补充检查；最终桌面关闭/另存流程在 100%/150% WebView2 绘制比例下复核。

### 下载与限制

主要分发产物：`PDFreader_0.1.0-rc.1_x64-setup.exe`。普通用户无需 Node.js/Python。已有最新 WebView2 Evergreen Runtime 时可离线阅读；缺失运行时则由安装程序联网下载。旧运行时兼容性未作全面承诺。

安装包 SHA-256：`76fab6c11d2345a9e79f4a098dfded5447af1061eea891efb57cdbf6716d460f`。请同时下载 SHA256SUMS.txt 核对。

候选版未签名。真实厂商验收和第三方阅读器互操作性仍有明确待验项，见 [候选版检查表](https://github.com/MPomelo/PDFreader/blob/main/docs/RELEASE_CHECKLIST.md)。本轮交付测试未调用付费翻译提供商；演示截图使用自制 PDF 和模拟译文。缺失 WebView2 时的下载分支及全新 Windows 虚拟机环境尚未独立验证。该版本不标记为正式稳定版。
