# 多文档标签与统一设置

## PDFreader 2.2.0 的工作区

1. 在窗口顶部展开「下栏」或「右栏」，各栏的加号都可打开文件或新建标签。顶部工具栏跟随最后操作的栏。按 `F6` 或 `Shift+F6` 顺序切换操作栏。
2. 用栏位标签菜单移栏，也可拖动标签到另一栏的标签行。分隔线支持鼠标拖动与方向键调整。临时最大化、收起和恢复比例均保留当前文档会话。
3. 新建译文标签后，选择跟随上栏、下栏、右栏或固定到 PDF。新建 AI 对话后，在「设置 → AI 对话」配置模型和 API 密钥。用 PDF 选区菜单的「问 AI」或对话里的材料入口添加选区与当前页，审阅后按「发送」。
4. 重启时恢复布局和已保存的本机文件。无法打开的文件会显示重新定位入口。可从对话历史再次打开本地对话，也可开启临时会话。

下文记录工作区早期版本的设计和验证历史。

2026-11-17 用户追加范围：允许同时打开多个 PDF，以浏览器式标签呈现；减少译文侧栏信息；增加统一设置；重排顶部工具栏并替换含义模糊的图标、移除重复的侧栏开关。

这是用户明确授权的 STAGE-05 范围增补，覆盖旧方案“首版不做多标签”的限制。未自动进入 STAGE-06；此前阶段的其他待验事项不据此视为通过。当前状态和最终程序校验见 STATUS.md 与 test-results/workspace/final-manifest.json。

## 新界面

- 标签栏显示文件名、未保存圆点、关闭按钮及加号。通过“打开”或拖入可同时打开 PDF、Markdown 和 TXT。
- 第二层为常用工具：左侧唯一“文档”入口管理目录、最近和笔记；打开/导出、页码、缩放、查找、批注、翻译分组排列；右侧为扳手“工具”和齿轮“设置”。已移除原先右上角三枚重复面板/阅读图标。
- 工具菜单保留页面缩略图、旋转、打印、专注阅读和更多 PDF 工具。PDF.js 顶部按钮由宿主工具栏协调，原有菜单、批注参数和阅读内核继续复用，未重写 PDF 编辑器。
- 译文侧栏只保留选区翻译入口、正文和复制/重译/笔记/源码动作；原文、思考、模型/耗时/用量及源码详情默认折叠。成功通知改为短暂浮动提示，不挤占文档高度。

## Markdown 和 TXT

- 在“＋”菜单新建 Markdown 或 TXT。打开已有 Markdown 默认显示预览，通过顶部按钮切换为源码或左右分栏。
- 文本标签可按 Ctrl+F 查找和替换、Ctrl+S 保存、Ctrl+Shift+S 另存为。TXT 按原样显示符号。遇到无法识别的旧文件时选择编码。状态栏显示当前编码和换行方式，混用多种换行符的文件编辑后按主要格式保存。
- 可通过“插入图片”、拖入或粘贴将图片插到 Markdown 光标处。首次保存新文档时写入图片，已有文档的图片即时保存到同名 `.assets` 文件夹。搬移或备份笔记时，请连同附件文件夹一起移动。手动清理前可先确认其他笔记是否引用该图片。
- 磁盘文件被外部修改或移除时，使用“另存为”保留当前编辑。原生桌面版支持本地附件和旧编码保存。

## 设置

| 分类 | 可用选项 |
| --- | --- |
| 阅读与外观 | 浅/深主题、首次打开缩放、恢复进度、选区浮窗入口、默认展开原文、直接显示模型/耗时/用量 |
| 翻译偏好 | 目标语言、流式输出、简/长模板、领域预设/自定义要求、术语表、仅本次运行的自动选区翻译 |
| API 服务 | 配置/模型/地址/鉴权、原生密钥、超时/输出上限、可选模型列表、用户主动触发的固定样例测试 |
| 本地数据 | 清理当前文档缓存、导出全部笔记；清缓存不删除笔记 |

阅读与外观立即保存。翻译与服务设置修改后统一点击“保存设置”，未保存关闭会提示；保存后通知各标签重新载入配置，不自动发送文字。密钥仍仅提交原生安全存储，不回传已有密钥。新建设置窗口不会主动测试服务。

设置窗口可在未打开 PDF 时使用。自动选区翻译每次启动仍默认关闭，开启后仅对当前活动标签生效；设置窗口打开期间暂停自动触发。

## 标签与数据保护

每份 PDF 使用独立 DocumentPane / ReaderAdapter / PDF.js 会话；切换采用可测量但不可交互的隐藏视图，不销毁 Worker、选区、页码、批注或译文。打开并转移文件字节后释放宿主字节引用。不同文件副本即使内容相同也可以各开一个标签；重复打开同一路径（浏览器预览为同名同内容）定位已开的标签。

每标签的 TranslationPanel 独立保留请求 ID、文档 ID、译文和取消门禁。后台结果只更新自己的标签；关闭标签会销毁会话并取消请求，迟到结果不能填入其他标签。设置保存后的已完成旧译文仍保留其原始请求语言/领域，保存笔记不会被新配置误标。

切换不需要导出批注。关闭标签先结束编辑并检查该标签，提供保存/放弃/取消；取消文件另存不关闭标签。关闭整个窗口逐一检查所有标签，不能只检查当前文档。导出目标与确认绑定具体标签，其他标签的修改不会混入，原 PDF 继续默认保护。

快捷键：Ctrl+O 打开；Ctrl+Tab / Ctrl+Shift+Tab 切换；Ctrl+1～8 定位标签、Ctrl+9 到最后；Ctrl+W 关闭当前；Ctrl+S 保存当前文本或导出 PDF 批注；Ctrl+Shift+Enter 翻译当前选区。PDF 内焦点同样转发相关快捷键，设置输入与模态对话框避让。

各文档进度独立记录；启动时显式多文件参数优先，否则按阅读偏好恢复最近一份本地文档。本轮没有新增“恢复整个上次标签会话”或系统文件关联/单实例启动转发，后者仍在 STAGE-06 的原有边界内。
